# Keyboard SHORTCUTS
All necessary SHORTCUTS for you.

**Desktop**
1. Windows+V = open clipboard
2. Clt+O = opens a document from folder
3. Alt+Tab = switch between open application
4. Win+Up/Down = minimize/maximize a window

**Browser**
5. Clt+N = opens a new window
6. Clt+Sht+N = new incognito window
7. Clt+T = opens a new tab
8. Clt+W = close current tab
9. Alt+F4 = close current application
10. Only F5 = refresh webpage
11. Clt+D = bookmark current webpage
12. Clt+L = highlights address bar

**Basic**
1. Clt+0 = resets zoom to 100%
2. Clt+'-' = zoom out
3. Clt+'+' = zoom in
4. Clt+X = cut
5. Clt+C = copy
6. Clt+V = paste
7. Clt+P = print
8. Clt+A = select all
9. Clt+S = save
10. Clt+Z = undo
11. Clt+Y = redo
12. Clt+F = find next

**VS Code**
1. code . = opens vs code from folder in the current path
2. cmd = opens cmd from folder in the current path
3. Clt+/ = comments a line or section

**VS code setup**
1. Download x64 file from code.visualstudio.com
2. Download python extension from extensions.
3. Install and then select python interpreter from vs code.
